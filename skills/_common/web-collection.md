# 采集类 skill 共享约束

适用于 `ministry-news-daily` 与 `policy-keyword-tracker`。本文件是两者共享段落的**唯一手写主源**，与各自 `SKILL.md` 冲突时以本文件为准；写作规则仍一律以 `prompts/` 主源为准。

## 信源基线（优先官方一手来源）

- 中国政府网 `www.gov.cn`。
- 对口/各部委官网（具体侧重见各 skill 的任务差异条目）。
- 必要时辅以新华社、人民网等权威转载，但**以部委官网原文为准**。

## 访问约束（务必遵守）

- **访问工具**：只用只读检索工具 `WebSearch` / `WebFetch` 获取**公开发布页**；不使用浏览器自动化、批量爬虫或任何登录态抓取，不抓取需登录、内网或非公开的页面。
- **访问频率**：低频、克制。先用 `WebSearch` 命中具体页面，再用 `WebFetch` 取该页；逐个站点**串行**访问，不对同一站点并发或高频请求，不深翻全站、不做整站抓取。
- **遵守站点规则**：尊重 robots 与版权，只摘录标题与要点并附原文链接，不整篇转载、不绕过访问限制。
- **失败容错**：单个站点访问失败或超时即跳过并标注「未取到」，不反复重试压垮目标站。

## 输出与保存路径（共享部分）

- 路径约定以主源 `prompts/core/workflow.md`「输出根目录 / 子目录映射」为准，不另立规则。
- 根目录默认 `~/official-document-drafting-output/`，或环境变量 `OFFICIAL_DOC_OUTPUT_DIR`。
- 成稿命名 `YYYYMMDD-…-vNN.{md,docx}`，采集底稿存 `-materials.md`；同名不覆盖、递增 `-vNN`。用户指定路径时以用户为准，不写入仓库目录。
- **业务素材同目录（最小授权）**：采集底稿、成稿、`.docx` 与引用图片落在同一子目录、用 `./` 引用，运行时只对该目录授读写权、不跨目录拉素材，详见 `AGENTS.md`「业务素材同目录与最小授权」与 `prompts/core/workflow.md`。

## 无 agent 环境（网页/离线）降级模式

- 联网采集需要 agent + 联网工具；没有 agent/skill 环境时无法自动采集。
- 此时退化为「人工采集 + 离线提示词成稿」：用户自行从各部委官网摘取素材、人工整理后，连同 `dist/offline/default/doc-types/<文种>/prompt.md` 一起粘贴给任意大模型，即可得到同样结构的成稿。
- 成稿能力已完整进入离线提示词；skill 额外提供的只是「自动采集 + 访问约束」这一层，离线环境由人工替代。

## 边界底线

- 真实性优先：只汇总**检索到且有来源**的事实；研判性内容与建议要与已核实事实分段，并明示是判断而非新事实。
- 写作规则一律以 `prompts/doc-types/<文种>/spec.md` 主源为准，skill 不复制规则。
- 仅做信息汇总与成稿，不代表任何机关口径；涉密、内部或未公开信息不采集。
- 需要校验成稿结构时，转 `document-qa` skill（`src/scripts/check_sections.py <type>`）。
