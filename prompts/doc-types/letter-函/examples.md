# 函示例

## 适用任务
- 用户说：请就“我的刀盾”传播素材协作事宜，起草一份商洽函。

## 推荐题名
- 关于商请支持“我的刀盾”传播素材整理工作的函

## 范文
```markdown
# 关于商请支持“我的刀盾”传播素材整理工作的函

## 主送单位

[主送单位]：

因推进“我的刀盾”传播素材整理工作需要，进一步盘活用好相关传播资源，提升内容供给质量和传播效能，现将有关事项函告如下。

一、协作背景

根据[牵头单位]工作部署，我单位正集中开展“我的刀盾”传播素材的摸排、归集和规范入库工作。鉴于贵单位在相关领域形成并留存了较为丰富的图文、音视频素材，与本项工作关联密切，特致函商请贵单位予以支持配合。

二、商请事项

一是请贵单位协助梳理[统计期]以来形成的相关传播素材，逐条登记来源、形式、时间和使用情况，形成素材台账。二是请贵单位对拟提供素材的内容导向和版权权属先行核查，确保权属清晰、使用合规。三是请贵单位明确一名联络人，负责对接素材报送和后续协调事宜。

三、配合事项

请贵单位于[反馈时限]前，将素材台账及电子文件、联络人信息反馈我单位[承办处室]。如在素材范围、报送方式等方面有不同意见，欢迎随时沟通协商。

特此函达，请予支持为盼。

## 落款

[发函单位]
[日期]

## 附注

（联系人：[联系人] 联系电话：[固定电话]，[手机号]）
```

## 常见误写
- 误写：对平行或不相隶属单位使用“请你单位务必于X日前完成报送”等命令式部署口吻。→ 修正：函属平行往来，应称“贵单位”，用“商请”“请予支持为盼”等平等、得体的措辞。
- 误写：把本应商洽的事项升格为请示，以“妥否，请批示”收尾，向不相隶属单位请求批准。→ 修正：不相隶属机关之间商洽、询问、答复用函，结尾用“特此函达”“请予支持为盼”，不混用请示的行文关系。
- 误写：一函之中既商请素材协作，又顺带通报进展、布置其他任务，事项庞杂。→ 修正：坚持一函一事，事项闭合，其他事项另行行文。
