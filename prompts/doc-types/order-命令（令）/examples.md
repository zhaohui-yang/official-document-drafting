# 命令（令）示例

## 适用任务
- 用户说：请为某项已经依法审议通过的规章拟制一份发布令。

## 推荐题名
- ［发布主体］令（第［文号］号）

## 范文
```markdown
# ［发布主体］令

第［文号］号

　　《［规章或办法名称］》已经［日期］［审议或批准机关／会议届次］审议通过，现予公布，自［施行日期］起施行。

　　各级各部门要严格遵照执行，确保各项规定落到实处。

　　　　　　　　　　　　　　　　　　　　　　　　　　［签署人职务］　［签署人姓名］

　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　［签署日期］
```

## 范文（部令子型：公布部门规章）
```markdown
# ［部门名称］令

第［文号］号

　　《［部门规章名称］》已经［日期］［第×次部务会议］通过，现予公布，自［施行日期］起施行。

　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　部长　［签署人姓名］

　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　［签署日期］
```

## 常见误写
- 误写：一般部门为部署日常工作擅自行文「××局令」。
  → 修正：「令」的使用权限严格，须由法定主体（如主席、国务院、有规章制定权的部门首长）在公布规章、施行强制性措施等法定情形下使用；一般事务应改用「通知」「决定」。
- 误写：把发布令写成「现将《……》印发给你们，请遵照执行」的通知口吻。
  → 修正：发布令须用刚性句式「《……》已经……审议通过，现予公布，自……起施行」，并具名签署、标明令号与施行日期。
- 误写：嘉奖令与表彰决定／通报混用，正文写成「特此通报」。
  → 修正：嘉奖令保持最高指令性与庄重语域，落到「予以嘉奖」并签署；一般表彰宜用「决定」或「通报」，不越级套用「令」。
