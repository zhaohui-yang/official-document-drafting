# 通报示例

## 适用任务
- 用户说：请就“我的刀盾”传播素材整理工作进展情况起草一份通报。

## 推荐题名
- 关于“我的刀盾”传播素材整理工作进展情况的通报

## 范文
```markdown
# 关于“我的刀盾”传播素材整理工作进展情况的通报

[各有关单位]：

近期，各单位认真贯彻[牵头单位]关于开展“我的刀盾”传播素材整理工作的部署要求，集中力量摸排归集、规范入库，工作取得阶段性成效。现将有关情况通报如下。

一、基本情况

自工作启动以来，各单位主动作为、扎实推进。截至[统计时点]，累计清点登记各类传播素材[数量]件，建立素材台账[数量]份，完成分类入库[比例]，重点素材标注可用范围和使用要求[数量]件。其中，[单位名称]、[单位名称]部署早、推进快，台账要素齐全、归集质量较高；[单位名称]结合实际探索建立素材命名和调用规范，为后续复用提供了有益经验。总体看，工作进展与时间节点要求基本相符，底数逐步清晰，归集渠道初步打通。

二、评价分析

各单位的做法表明，把素材整理作为基础性、长期性工作来抓，坚持质量优先、应收尽收、安全合规，就能做到底数清、分类明、可调用、可复用。但工作中也存在一些不容忽视的问题：个别单位重视不够，摸排不全、台账要素缺项，存在漏登、错登现象；少数单位对内容导向和版权权属审核把关不严，存在权属不清的素材入库；部分单位进度滞后，截至[统计时点]仍未报送台账。这些问题反映出有的单位责任压得不实、规范执行不到位，必须引起重视、抓紧整改。

三、工作要求

现提出以下工作要求。一是对标补齐。进度滞后、要素缺项的单位要立即查漏补缺，于[整改时限]前完成台账完善和素材报送，确保不留盲区。二是严格把关。各单位要对拟入库素材逐件核查内容导向和版权权属，由分管负责同志审定后入库，坚决防止问题素材流入。三是压实责任。各单位主要负责同志要切实负起领导责任，明确专人专责，把整理工作纳入近期重点任务统筹推进。[牵头单位]要加强统筹协调和督促指导，确保各项任务落到实处。

特此通报。

## 落款

[发文单位]
[日期]
```

## 常见误写
- 误写：通报通篇只写“各单位高度重视、扎实推进、成效明显”，没有数据和事实支撑。→ 修正：基本情况要用清点数量、入库比例、报送时限等可核对的事实和数据说话，评价分析才站得住。
- 误写：把通报写成知照性通知，只交代情况、不作评价、不提要求。→ 修正：事实、评价、要求三层要分明，结尾落到“现提出以下工作要求”的具体整改和防范措施。
- 误写：批评性内容情绪化、扣帽子，对尚未查清的责任提前下定论。→ 修正：先把事实、过程、结果写清，再作分寸得当的性质判断，未核实的责任和结论不写成定论。
