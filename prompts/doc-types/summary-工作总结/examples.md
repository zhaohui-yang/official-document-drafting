# 工作总结示例

## 适用任务
- 用户说：请围绕“我的刀盾”传播素材整理工作，写一份阶段性工作总结。

## 推荐题名
- “我的刀盾”传播素材整理工作总结

## 范文

```markdown
　　　　“我的刀盾”传播素材整理工作总结

　　一年来，[牵头单位]围绕“我的刀盾”传播素材整理工作，坚持问题导向、注重机制建设，圆满完成了全年各项任务。一年来累计整理传播素材[X]件、形成专题报告[X]份，监测预警苗头性信息[X]条，工作整体平稳有序、质量稳步提升。现将主要情况总结如下。

　　一、基本情况

　　本总结周期为[X年X月]至[X年X月]。一年来，工作重心由“被动收集”向“主动整理、动态研判”转变，建立起“监测—整理—研判—报送”的常态化流程。全年共开展集中整理[X]轮，覆盖[X个]平台，形成结构化素材库[X]条，为后续研判和处置提供了基础支撑。

　　二、在素材采集整理上下功夫，基础工作更加扎实

　　我们始终把素材采集整理作为基础性工作来抓，确保“底数清、来源明”。在重视程度上，专门成立[X]人整理小组，明确专人专责，将素材整理纳入日常重点台账。在具体措施上，统一了素材分类标准和登记口径，建立来源标注和待核实标注制度，对未经核实的信息一律单列、不与已核实信息混计。从实际效果看，全年累计整理素材[X]件，登记准确率约[X]%，较上年提升[X]个百分点；在[X月]的[专项任务]中，整理小组[X]小时内即完成[X]条素材的归集和初筛，为快速研判赢得了时间。

　　三、在研判报送上求实效，决策支撑更加有力

　　我们坚持“整理是基础、研判是关键”，着力把素材优势转化为研判优势。在重视程度上，建立每周例会和重大情况即时会商机制，做到研判常态化。在具体措施上，推行“事实摘要＋趋势研判＋工作建议”的标准化报送模板，明确事实与研判分列，提升了报送的规范性和可读性。从实际效果看，全年形成专题报告[X]份、动态简报[X]期，多份报告获领导批示采纳；在[X月]的舆情高热期，我们提前[X]天作出趋势研判，相关建议被采纳后，话题情绪化比例由[X]%降至[X]%，有效避免了态势升级。

　　四、存在问题

　　在肯定成绩的同时，必须清醒看到工作中的短板。一是素材整理智能化程度不高，仍以人工筛选为主，效率受人手制约，遇到突发高热任务容易出现积压。二是研判经验固化不足，骨干个人经验多、可复制的方法少，人员变动会影响研判连续性。三是跨部门数据共享不畅，部分平台数据获取仍需逐次协调，影响整理和研判时效。这些问题，制约着工作向更高水平迈进，必须下大气力解决。

　　五、下一步打算

　　下一步，我们将聚焦短板、持续改进。一是推进整理工具升级，探索引入半自动化筛选，把人力从重复劳动中解放出来。二是沉淀研判方法，将成熟经验转化为标准化指引，降低对个人经验的依赖。三是推动数据共享机制化，争取相关平台数据的稳定权限，提升整理研判时效。下一步将持续抓好贯彻落实。

　　[单位名称]
　　[X年X月X日]
```

## 常见误写
- 罗列数字无提炼：通篇“整理X件、报送X份、会商X次”流水账，看不出规律和经验 → 用“结论句＋硬数据＋案例”三明治写法，先下结论句，再以数据和典型案例支撑。
- 只报喜不报忧：成效写得满满当当，问题一笔带过或干脆不写 → 成效和问题都要写实，并区分“问题短板”与“原因分析、改进方向”。
- 总结写成工作方案：“下一步打算”喧宾夺主、铺陈大段未来安排 → 总结以复盘事实、提炼经验为主，下一步打算点到为止、与前文成效问题相呼应。
