# 纪要示例

## 适用任务
- 用户说：请根据会议材料整理一份关于研究“我的刀盾”网络传播情况的专题会议纪要。

## 推荐题名
- 关于研究“我的刀盾”网络传播情况的专题会议纪要

## 范文
```markdown
# 关于研究“我的刀盾”网络传播情况的专题会议纪要

## 会议基本信息

- 会议名称：研究“我的刀盾”网络传播情况专题会议
- 时间：[日期][时段]
- 地点：[会议地点]
- 主持人：[主持人姓名及职务]

## 出席

[出席人员姓名及职务（按职务、层级排列）]

## 参加

[参加、列席人员所在单位及姓名]

## 记录

[记录人姓名]

　　[日期]，[主持人姓名及职务]主持召开专题会议，研究部署“我的刀盾”网络传播情况有关工作。会议听取了[牵头单位]关于近期“我的刀盾”网络传播总体情况的汇报，研究了素材使用、舆情应对和协同处置中存在的突出问题，审议了《[相关工作方案名称]》。现将会议议定事项纪要如下。

　　会议认为，做好“我的刀盾”网络传播工作，事关[相关工作大局表述]，意义重大、影响深远。一是近一个时期以来，各有关单位按照统一部署，加强统筹、密切配合，传播工作总体平稳有序，取得了积极成效。二是当前传播形势依然复杂，素材使用不够规范、口径衔接不够顺畅、协同处置不够及时等问题仍然存在，必须高度重视、切实加以解决。三是面对新形势新要求，各单位要进一步增强责任感和紧迫感，把思想和行动统一到会议确定的部署上来，确保各项工作落实落细。

　　会议决定，一、统一传播素材使用口径。由[牵头单位]牵头，会同[配合单位]抓紧梳理现有传播素材，建立分类清单和审核机制，未经审核的素材一律不得对外使用。

　　二、健全舆情监测和协同处置机制。由[责任单位]负责完善监测预警体系，明确分级响应和处置流程，遇有重要情况第一时间报告、第一时间处置。

　　三、加强信息发布管理。各单位对外发布相关信息，须按规定履行审批程序，确保口径一致、表述准确，不得擅自表态、各自为政。

## 责任分工

[牵头单位]于[时间]前完成传播素材分类梳理和审核机制建设，并报[审定主体]审定。

[责任单位]于[时间]前完成舆情监测和协同处置机制的修订完善，形成书面方案报会。

## 后续要求

各有关单位要切实抓好会议议定事项落实，明确专人负责，于[时间]前将落实情况书面反馈[牵头单位]汇总；[牵头单位]要加强跟踪督办，重要情况及时报告。本纪要所涉事项尚未公开，各单位务必严格保密，不得擅自扩散、对外发布和引用。

## 版记

主送：[主送单位]

抄送：[抄送单位]

审核：[审核人]
```

## 常见误写
- 不要把纪要写成会议记录：纪要记载形成共识的议定事项，不逐字照录发言、不罗列无结论的来回讨论。
  - 误写：“[某同志]说，我认为素材应当统一管理……[另一同志]说，我也同意……”
  - 修正：“会议认为，传播素材使用不够规范的问题必须切实解决。会议决定，由[牵头单位]牵头建立素材分类清单和审核机制。”
- 不要用第一人称或同名小标题：以“会议”为主语，“会议认为”“会议决定”作正文起句连续书写，不抬成二级标题。
  - 误写：另起一行写“## 会议决定”再分点。
  - 修正：“会议决定，一、……二、……”随正文连续展开。
- 不要把未达成一致的事项写成既定结论。
  - 误写：“会议决定，关于[争议事项]按[某方案]执行。”（实际尚未形成一致）
  - 修正：“关于[争议事项]，会议要求继续研究，补充完善后另行专题研究。”
