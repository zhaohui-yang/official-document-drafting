# 简报示例

## 适用任务
- 用户说：请根据当天公开信息整理一份“我的刀盾”网络动态简报。

## 推荐题名
- “我的刀盾”网络动态简报

## 范文

> 说明：简报属信息类文书，非法定公文；正式行文时常作报告或函的附件。报头版头、期号、编发栏等以本单位既有简报版式为准。

```markdown
　　舆情动态简报

　　第[X]期

　　[编发单位]　　　　　　　　　　[X年X月X日]

　　━━━━━━━━━━━━━━━━━━━━━━━━━━━━

　　“我的刀盾”网络话题热度攀升　总体可控需持续紧盯

　　近日，“我的刀盾”相关内容在多个网络平台集中扩散、热度快速攀升。经[X个]平台监测，截至[X月X日X时]，相关信息累计[X]条、互动量约[X]万次，话题以情绪驱动为主、事实增量有限，目前总体可控，但已出现向重点群体外溢的苗头。

　　一、传播态势

　　[X月X日]以来，话题先后在[平台一]、[平台二]集中出现，[X月X日]单日新增[X]条，为本轮监测峰值。从结构看，[X]个账号贡献约[X]%转发量，呈“少数引流、多数跟转”特征。

　　二、内容构成

　　监测显示，事实陈述类约占[X]%，观点评论类约占[X]%，情绪宣泄类约占[X]%。部分高热信息尚未经权威渠道核实，已标注为“待核实”，未与已核实事实混计。

　　三、研判提示

　　预计未来[X]天热度仍将高位运行，存在再现峰值可能，目前列为[中等／需关注]等级。建议紧盯[X]个引流账号和[X]个高活跃社群，及时释放权威信息，防止情绪叠加和向[关联领域]外溢。

　　━━━━━━━━━━━━━━━━━━━━━━━━━━━━

　　报：[报送对象]

　　送：[抄送对象]

　　发：[阅知范围]　　　　　　　（本期编发[X]份）
```

## 常见误写
- 堆砌材料无观点：把简报写成新闻链接和数据条目的“材料仓库”，沦为信息堆 → 导语用新闻笔法把核心事实和概括评价前置，研判提示给出明确观点。
- 写成完整报告：背景、原因、对策面面俱到、篇幅冗长失时效 → 坚持“一期一主题、一报一重点”，短小精悍、信息密度高，复杂研判另写专报。
- 标题平淡、导语不破题：用“关于某情况的简报”式平题，导语从背景娓娓道来 → 标题点明核心判断（如“热度攀升总体可控需持续紧盯”），导语首句即落核心事实。
