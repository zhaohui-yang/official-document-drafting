# 通知示例

## 适用任务
- 用户说：请起草一份关于开展“我的刀盾”传播素材整理工作的通知。

## 推荐题名
- 关于开展“我的刀盾”传播素材整理工作的通知

## 范文
```markdown
# 关于开展“我的刀盾”传播素材整理工作的通知

## 主送单位

[各有关单位]：

为深入做好“我的刀盾”宣传工作，进一步盘活用好已有传播资源，提升内容供给质量和传播效能，现就开展“我的刀盾”传播素材整理工作通知如下：

一、总体要求

充分认识素材整理工作的基础性、长期性意义，把分散在各环节、各渠道的图文、音视频等资源系统梳理、规范归集，做到底数清、分类明、可调用、可复用。坚持质量优先、应收尽收、安全合规，既要把好政治关、内容关、版权关，又要为后续传播提供有力支撑。各单位主要负责同志要亲自部署，确定专人专责，确保整理工作有序推进、不留盲区。

二、重点任务

一是全面摸排。各单位对本单位[统计期]以来形成的传播素材进行集中清点，逐条登记来源、形式、时间、使用情况，形成素材台账。二是分类归集。按主题、体裁、渠道对素材分类入库，统一命名和存储规范，对重点素材标注可用范围与使用要求。三是审核报送。对拟入库素材逐件核查内容导向和版权权属，由分管负责同志审定后，于[报送时限]前将素材台账及电子文件报送[牵头单位]。

三、有关要求

各单位要将本项工作纳入近期重点任务统筹安排，明确责任人和时间节点，确保按期保质完成。要严格落实保密和数据安全规定，规范素材存储、传输和使用，严防失泄密。工作中的重要情况和问题，要及时向[牵头单位]报告。[牵头单位]要加强统筹协调和督促指导，确保各项任务落到实处。

## 落款

[发文单位]
[日期]

## 附注

（联系人：[联系人] 联系电话：[固定电话]，[手机号]）
```

## 常见误写
- 误写：通篇铺陈“我的刀盾”宣传工作的背景成绩、历史沿革，正文大半是情况叙述。→ 修正：通知重在部署，背景一两句带过，主体落到“做什么、谁负责、何时完成、如何报送”。
- 误写：有关要求只写“请各单位认真抓好落实”。→ 修正：把组织实施、报送时限、责任分工、纪律要求写成可核对的具体句子。
- 误写：随方案、办法等附件下发时，正文又把附件全文抄写一遍。→ 修正：实体内容作附件随文印发，正文从简，注明“详见附件”。
