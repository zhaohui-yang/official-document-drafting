# 决定示例

## 适用任务
- 用户说：请就建立“我的刀盾”传播素材整理机制形成一份决定。

## 推荐题名
- 关于建立“我的刀盾”传播素材整理机制的决定

## 范文
```markdown
# 关于建立“我的刀盾”传播素材整理机制的决定

　　为加强“我的刀盾”传播素材的统一管理和规范使用，提升传播工作整体效能，根据[依据文件或政策名称]，结合[发文单位]工作实际，现就建立“我的刀盾”传播素材整理机制作出如下决定。

## 决定事项

　　一、建立传播素材统一整理机制。由[牵头单位]牵头，会同[配合单位]负责传播素材的归集、分类、审核和动态更新，对各类素材实行清单化管理，确保来源清晰、权属明确、调用有序。

　　二、明确素材审核把关责任。各类传播素材在对外使用前，须按权限履行审核程序，未经审核的素材一律不得对外发布；涉及重要事项的素材，按规定逐级报审，确保导向正确、表述准确。

　　三、健全素材使用监督机制。建立使用台账和检查通报制度，对擅自使用、违规使用素材的，依规依纪严肃处理，确保整理机制有效运行。

## 执行要求

　　本决定自发布之日起施行。各有关单位要切实提高认识，明确专人负责，抓紧抓实各项任务落实，于[时间]前将贯彻落实情况报[牵头单位]。[牵头单位]要加强统筹协调和督促检查，确保机制建得起、转得动、用得好。

　　特此决定。

## 落款

[发文单位]
[日期]
```

## 范文（公布式：修改、废止类）

### 适用任务
- 用户说：请就修改、废止部分“我的刀盾”传播素材管理规定形成一份公布式决定。

### 推荐题名
- 关于修改和废止部分“我的刀盾”传播素材管理规定的决定

```markdown
# 关于修改和废止部分“我的刀盾”传播素材管理规定的决定

　　《关于修改和废止部分“我的刀盾”传播素材管理规定的决定》已经[X年X月X日][发文单位]第[X]次[会议名称]通过，现予公布，自[施行日期]起施行。

　　一、对《[被修改文件名称]》予以修改（修改内容见附件1）。

　　二、对《[被废止文件名称]》予以废止（废止清单见附件2）。

　　本决定自[施行日期]起施行。

[发文单位]
[日期]

附件：1.[被修改文件名称]修改对照表
　　　2.废止文件清单
```

## 常见误写
- 不要把公布式决定写出缘由铺垫：公布修改废止类应开门见山公布，逐项点明处置对象与效力，细目挂附件，不展开说理。
  - 误写：“为规范传播素材管理，根据……，经研究，现对部分规定作如下修改和废止。”
  - 修正：“《……的决定》已经[X年X月X日][发文单位]第[X]次[会议名称]通过，现予公布……一、对《……》予以修改（见附件1）。二、对《……》予以废止（见附件2）。本决定自[施行日期]起施行。”
- 不要把决定写成一般工作方案或情况汇报：决定写已经作出的处理结论，结论明确、力度要强。
  - 误写：“下一步，我们考虑探索建立素材整理机制，初步设想……”
  - 修正：“现作出如下决定。一、建立传播素材统一整理机制，由[牵头单位]牵头……”
- 不要把决定与决议混淆：决定可由机关直接作出；决议必经会议表决、以会议名义发布。
  - 误写：在未经会议表决的机关发文中写“会议经讨论一致通过……特作如下决议”。
  - 修正：机关直接发文用“现作出如下决定”，结尾“特此决定。”
- 不要只讲背景、不明确决定内容。
  - 误写：通篇叙述传播素材管理的必要性，无具体决定事项。
  - 修正：背景依据从简，主体落到“决定事项”逐条列写处理结论、责任主体和效力边界。
