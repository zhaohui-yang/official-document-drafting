# 讲话稿示例

## 适用任务
- 用户说：请为［会议或活动名称］起草一篇动员部署讲话稿。

## 推荐题名
- 在［会议或活动名称］上的讲话

## 范文
```markdown
# 在［会议或活动名称］上的讲话

（［日期］，根据录音整理）

同志们：

　　今天，我们召开这次会议，主要任务是［会议目的与议题概述］，统一思想、压实责任，推动［工作事项］迈出实质性步伐。刚才，［发言或交流情况简述］，讲得都很好，我都同意。下面，我讲三点意见。

　　第一，关于怎么看——准确把握形势，深刻认识做好这项工作的重大意义。当前，［领域或全局形势的政论判断］。我们既要看到［有利条件与成绩］，更要清醒认识到［问题与短板］。形势逼人、挑战逼人、使命逼人。把这件事抓好，抓的是大局、抓的是长远、抓的是民心，丝毫不能懈怠。

　　第二，关于怎么办——突出重点、把准方向，明确推进工作的总体思路。要紧扣［指导思想或工作主线］，坚持［基本原则］，把功夫下在关键处、要害处。既要谋全局、把方向，又要抓具体、抓深入，做到方向不偏、力度不减、节奏不乱。

　　第三，关于怎么干——抓住关键、狠抓落实，确保各项任务落地见效。一要［任务部署第一项及要求］，明确责任、挂图作战；二要［任务部署第二项及要求］，强化协同、形成合力；三要［任务部署第三项及要求］，从严督导、传导压力。各级各部门要对号入座、各司其职，确保件件有着落、事事见成效。

　　最后，我强调几点：一是提高站位，切实把思想和行动统一到［决策部署］上来；二是压实责任，主要负责同志要亲自抓、负总责；三是严明纪律，以严的作风、实的举措保障工作落实。

　　让我们以更高标准、更实作风、更强担当，扎实做好各项工作，不辜负组织和群众的重托。

　　谢谢大家。
```

## 常见误写
- 误写：通篇「高度重视、统筹推进、扎实做好」等空话套话堆叠，没有具体判断和部署。
  → 修正：观点句要立得住、对得齐，形势判断用政论笔法，部署落到「一要、二要、三要」的可执行要求，避免「正确的废话」。
- 误写：写成文件口吻过重的通知或报告，称谓、过渡、节奏全无现场感。
  → 修正：保留「同志们：」开场（仅出现一次），点明场合目的，多用短句、少嵌套，按「怎么看—怎么办—怎么干」递进，结尾以提气收束。
- 误写：偏离主旨和领导意图，层级滥用、逻辑跳跃，数字罗列成堆。
  → 修正：紧扣一条主线谋篇，数据为论点服务而非堆砌，结尾用「最后，我强调几点」收口，做到立意高、落点实。
