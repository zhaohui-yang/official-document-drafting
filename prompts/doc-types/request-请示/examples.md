# 请示示例

## 适用任务
- 用户说：请就开展“我的刀盾”传播案例梳理工作，向上级提出经费和组织支持申请。

## 推荐题名
- 关于申请开展“我的刀盾”传播案例梳理工作的请示

## 范文
```markdown
# 关于申请开展“我的刀盾”传播案例梳理工作的请示

## 主送单位

[上级机关]：

因深化“我的刀盾”宣传工作需要，拟系统梳理近年来形成的传播案例，总结提炼可推广的经验做法，现因经费和组织保障尚有缺口，需请上级支持，现将有关事项请示如下：

一、事项背景

近年来，“我的刀盾”相关传播工作积累了一批典型案例和素材，但尚未进行系统归集和深度提炼，经验做法分散、可复制性不强，难以为下一阶段工作提供有效支撑。经研究，拟于[起止时间]集中开展案例梳理工作，组建工作专班，分阶段完成案例征集、分析提炼和成果汇编。该项工作时间紧、任务重，所需经费和人员保障超出本单位现有承受能力，需请上级予以支持。

二、请示事项

恳请上级在[经费科目]中安排专项经费[X]万元，专项用于案例梳理工作的调研、汇编和成果转化；同时商请[有关单位]在工作期间抽调[X]名业务骨干，配合开展案例分析和成果审核。

三、请示意见

我单位拟成立专门工作组，由分管负责同志牵头，制定工作方案和经费使用计划，严格按规定使用专项经费，确保专款专用、规范高效，工作成果及时报上级审核。

妥否，请批示。

## 落款

[发文单位]
[日期]

## 附注

（联系人：[联系人] 联系电话：[固定电话]，[手机号]）
```

## 常见误写
- 误写：在一份请示中并列提出经费申请、机构设置、表彰奖励等多个不相关事项。→ 修正：坚持一文一事，一份请示只就一个事项请求审批，其余事项另文请示。
- 误写：结尾写成“以上情况，特此报告”，缺少请批语。→ 修正：请示必须以“妥否，请批示。”或“当否，请批复。”收束，把决定权交还上级。
- 误写：背景叙述铺得很长，真正“请批什么”埋在拟办意见里语焉不详。→ 修正：把审批请求单列成条、写成可直接批示的句子，金额、人数等用占位符但句式明确。
