# 报告示例

## 适用任务
- 用户说：请根据现有材料，向上级汇报“我的刀盾”网络传播情况和下一步工作打算。

## 推荐题名
- 关于“我的刀盾”网络传播情况的报告

## 范文
```markdown
# 关于“我的刀盾”网络传播情况的报告

## 主送单位

[上级机关]：

按照上级关于加强宣传工作的部署要求，[统计期]以来，我单位扎实推进“我的刀盾”网络传播工作，传播声势和影响逐步扩大。现将有关情况报告如下：

一、基本情况

“我的刀盾”网络传播工作整体推进有序、态势向好。我单位坚持统筹策划、分众投放，构建起多平台协同的传播格局，主题内容覆盖面和到达率稳步提升。[统计期]内，累计发布各类作品[X]件，通过[X]个平台分发，形成了一批传播效果较好的内容产品，社会反响总体积极。

二、工作开展情况

我单位主要从三方面着力推进。一是强化内容策划，围绕重点主题组织选题，统一基调口径，推出系列图文和短视频作品，内容质量持续提升。二是优化传播渠道，整合自有平台与合作渠道资源，根据不同受众特点分类投放，重点作品阅读量、播放量达到[X]，互动数据稳步增长。三是健全工作机制，明确策划、制作、审核、发布各环节责任，建立素材报送和效果反馈台账，确保流程规范、导向可控。

三、存在问题

工作中也还存在一些短板。一是优质原创内容供给不足，部分作品同质化，缺乏有分量、能破圈的精品。二是渠道协同还不够顺畅，平台间数据共享和联动投放机制尚不健全，传播合力有待增强。三是专业力量相对薄弱，策划、制作骨干人手紧张，制约了内容生产的持续性和创新性。

四、下一步打算

下一步，我单位将聚焦提质增效，强化精品意识，集中力量打造一批主题鲜明、形式新颖的拳头产品；健全多平台协同投放和效果评估机制，提升传播精准度；加强队伍建设和业务培训，充实专业力量。恳请上级在内容统筹和资源调度上给予更多指导支持。

特此报告。

## 落款

[发文单位]
[日期]

## 附注

（联系人：[联系人] 联系电话：[固定电话]，[手机号]）
```

## 常见误写
- 误写：在报告主体或结尾夹带“拟申请专项经费[X]万元，妥否，请批示”等请批事项。→ 修正：报告只报情况，确需审批的另行专文请示，或请示、报告分写，结尾用“特此报告。”。
- 误写：通篇只罗列成绩和数据，回避问题，也不写下步安排。→ 修正：实事求是、喜忧皆报，单设“存在问题”板块，并写明下一步打算。
- 误写：板块下只堆口号，如“高度重视、扎实推进、成效显著”。→ 修正：按“概述＋一是、二是、三是”展开，每点写清做法、进展、成效，数据用占位符但句子落到实处。

## 另一子型范文（制式/年度报告）

### 适用任务
- 用户说：请按规定格式撰写本单位年度政务公开工作报告。

### 推荐题名
- [发文单位]本年度政务公开工作报告

### 范文
```markdown
# [发文单位]本年度政务公开工作报告

根据《中华人民共和国政府信息公开条例》和有关规定，现将[发文单位]本年度政务公开工作情况报告如下：

一、总体情况

本年度，[发文单位]坚持以公开为常态、不公开为例外，依法依规推进政务公开各项工作，公开内容、渠道和实效持续优化。一是健全制度机制，修订完善信息公开和审查保密相关办法[X]项，明确各环节责任。二是拓展公开渠道，依托门户网站、政务新媒体等平台集中发布，全年主动公开各类政府信息[X]条。三是加强解读回应，围绕重点政策组织解读[X]次，回应社会关切[X]件。

二、主动公开政府信息情况

本年度主动公开工作总体规范、覆盖面进一步扩大。我单位按照公开目录及时更新信息，全年通过门户网站公开[X]条，通过政务新媒体公开[X]条；其中财政预决算、重大建设项目等重点领域信息[X]条。同时，对历史公开信息开展清理核查，更新和补录[X]条，确保信息准确可查。

三、依申请公开办理情况

本年度共收到政府信息公开申请[X]件，已办结[X]件，其中予以公开[X]件，部分公开[X]件，依法不予公开[X]件，告知作出更改补充或通过其他途径办理[X]件。所有申请均在法定时限内答复，未发生因办理不当引发的争议。

四、行政复议和行政诉讼情况

本年度因政务公开工作引发的行政复议[X]件，行政诉讼[X]件。相关案件均依法依规应对处理，办理结果总体平稳。

五、存在的主要问题及改进情况

工作中仍存在一些不足。一是部分领域公开的及时性、完整性有待提升，个别栏目更新不够同步。二是政策解读形式较为单一，互动性和针对性需进一步增强。针对上述问题，我单位已完善信息报送和审核台账，规范更新时限，并丰富解读和回应方式，相关改进措施正逐步落实见效。

六、其他需要报告的事项

本年度政务公开工作未发生需要单独说明的重大事项。下一年度，[发文单位]将继续围绕公开标准化、规范化要求，深化重点领域信息公开，提升解读回应水平。
```

### 常见误写
- 误写：制式年报误用缘由式起笔“按照上级部署要求，现将……报告如下”。→ 修正：年度报告以依据式起笔，写明所依据的条例或办法，再“现将本年度……报告如下”。
- 误写：自行调整或删减规定栏目，把“依申请公开办理”“行政复议和行政诉讼”等并入其他段落。→ 修正：严格按主管部门规定的固定栏目顺序逐项铺排，不漏项、不并项。
- 误写：栏目下只写空泛概述，不落统计数字，或在结尾套用“特此报告”。→ 修正：分项统计数字一律用占位符 [X] 撑实篇幅，结尾以事项句或下一步打算自然收束，不用结束套语。
