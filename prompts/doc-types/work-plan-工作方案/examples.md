# 工作方案示例

## 适用任务
- 用户说：请就［事项名称］拟定一份专项工作方案，要求目标可考核、任务可落地。

## 推荐题名
- ［事项名称］工作方案

## 范文
```markdown

　　为［工作目的］，根据《［政策依据或上级文件名称及文号］》，结合［本地区／本部门实际］，制定本方案。

　　一、总体要求

　　二、主要任务

　　（一）［任务一名称］。目标：［本项任务要达到的标准］；举措：［具体做法］；责任：牵头单位［责任单位］，配合单位［协办单位］；标准：［日期］前完成，达到［验收或完成标准］。

　　（二）［任务二名称］。目标：［本项任务要达到的标准］；举措：［具体做法］；责任：牵头单位［责任单位］，配合单位［协办单位］；标准：［日期］前完成，达到［验收或完成标准］。

　　（三）［任务三名称］。目标：［本项任务要达到的标准］；举措：［具体做法］；责任：牵头单位［责任单位］，配合单位［协办单位］；标准：［日期］前完成，达到［验收或完成标准］。

　　三、实施步骤

　　（一）动员部署阶段（［起止时间］）：制定方案、明确分工、召开部署会。

　　四、保障措施

　　（一）加强组织领导。成立由［牵头领导］任组长的工作专班，统筹协调、压实责任。
　　（二）强化资源保障。落实［资金、人员、技术等保障安排］，确保各项任务有支撑。
```

## 常见误写
- 误写：主要任务只写原则，「切实加强、统筹推进、扎实做好」，没有责任主体和完成标准。
  → 修正：每项任务都拆到「目标—举措—责任—标准」，明确谁来做、做到什么程度、何时完成。
- 误写：工作目标空泛，无量化指标、无时间节点。
  → 修正：目标须可考核，给出量化指标与时间节点（占位符），确保可量化、可考核、可追溯。
- 误写：把方案写成工作总结或通知，只回顾成绩或只发部署号召。
  → 修正：方案以「总体要求—主要任务—实施步骤—保障措施」谋篇；若作为通知附件印发，正文不再重复通知式部署语气。
