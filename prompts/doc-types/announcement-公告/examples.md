# 公告示例

## 适用任务
- 用户说：请围绕“我的刀盾”素材征集事项起草一份公告。

## 推荐题名
- 关于征集“我的刀盾”传播素材的公告

## 范文
```markdown
# 关于征集“我的刀盾”传播素材的公告

为进一步盘活用好传播资源，丰富“我的刀盾”优质内容供给，现面向社会公开征集相关传播素材。有关事项公告如下。

一、征集范围

围绕“我的刀盾”主题创作的图文、音视频等各类传播素材，内容应导向正确、主题鲜明、形式健康。应征素材的著作权及相关权利应权属清晰，不得侵犯他人合法权益。

二、提交方式

应征者于[征集时段]内，通过[提交渠道]提交素材文件及作者信息、权属说明等材料。单件素材的规格、格式等具体要求见[附件/附图]。

三、有关说明

经评审入选的素材，由[发布单位]按公布规则予以采用，并依约定方式处理相关权利事宜。提交即视为知悉并同意本公告及相关规则。征集过程中的具体问题，可向下列联系人咨询。

特此公告。

## 落款

[发布单位]
[日期]

## 附注

（联系人：[联系人] 联系电话：[固定电话]，[手机号]）
```

## 常见误写
- 误写：公告写上“各有关单位：”等主送对象，并使用“请你单位认真落实”的内部部署口吻。→ 修正：公告面向国内外宣布事项，不写主送机关、不写称谓，直接进入事项，语域庄重、权威、简洁。
- 误写：把仅需一定范围内遵守的强制性事项（如禁止、罚则）写成公告。→ 修正：须公众遵守的约束性事项应改判为通告；公告用于向国内外宣布重要或法定事项，二者不可混用。
- 误写：普通事务性安排（如内部会议通知、一般工作提示）也冠以“公告”发布。→ 修正：事项层级不足时改用通知或其他文种，仅在事项足够重大时使用公告。
