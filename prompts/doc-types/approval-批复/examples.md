# 批复示例

## 适用任务
- 用户说：请对下级报送的“我的刀盾”传播素材整理请示作出批复。

## 推荐题名
- 关于同意开展“我的刀盾”传播素材整理工作的批复

## 范文
```markdown
# 关于同意开展“我的刀盾”传播素材整理工作的批复

## 主送单位

[来文单位]：

你单位《关于申请开展“我的刀盾”传播素材整理工作的请示》（[来文字号]）收悉。现批复如下：

一、同意你单位开展“我的刀盾”传播素材整理工作。同意按你单位报来的工作安排，于[起止时间]组织开展素材摸排、分类归集和审核入库，建立规范、可复用的素材资源库。

二、原则同意所提经费保障安排。同意在[经费科目]中安排专项经费[X]万元，专项用于素材整理工作，所需经费由你单位按规定程序申请拨付，严格落实专款专用，不得挪作他用。所提抽调人员事项，由你单位与[有关单位]商定后组织实施。

三、关于工作要求。你单位要严格把好内容导向关和版权权属关，落实保密和数据安全规定，规范素材存储、传输和使用。工作完成后，将素材台账和成果汇编报我单位备案；工作中的重要情况和问题，要及时报告。

请遵照执行。

## 落款

[批复单位]
[日期]
```

## 常见误写
- 误写：开头直接写“同意你单位开展素材整理工作”，不引来文标题和发文字号。→ 修正：先引来文，“你单位《……的请示》（[来文字号]）收悉。现批复如下：”，做到有请示才批复。
- 误写：原请示包含开展工作、经费、抽调人员三项，批复只笼统写“原则同意”，不交代边界。→ 修正：坚持一请示一批复，逐项对应作出明确结论，分别说清同意范围和限制条件。
- 误写：把同意与否的结论埋在长段执行要求里，态度含糊。→ 修正：批复意见置于首句、正面表态，正文宜短、直、硬，结尾以“请遵照执行。”收束。

## 适用任务（长结构型）
- 用户说：请就下级报送的[规划／方案名称]核准请示，作出按维度分条的长篇批复。

## 推荐题名
- 关于《[规划／方案名称]》的批复

## 范文
```markdown
# 关于《[规划／方案名称]》的批复

## 主送单位

[来文单位]、[归口审查部委]：

你单位《关于报请审批〈[规划／方案名称]〉的请示》（[来文字号]）收悉。现批复如下：

一、原则同意《[规划／方案名称]》（以下简称《[规划／方案简称]》）。《[规划／方案简称]》以[指导思想或工作主线]为统领，立足[区域／领域定位]，明确了[规划期或实施期]的[总体目标]，作为[适用范围]内开展[相关工作]的基本依据，由你单位组织实施。

二、严守[底线领域]安全底线。[底线指标一]不低于[X]，[底线指标二]不少于[X]，[红线或边界]不得突破。要把[约束性指标]作为刚性约束，落实到[空间单元或责任主体]，确保[底线目标]稳定可控。

三、优化[结构或格局领域]总体格局。统筹[要素一]、[要素二]、[要素三]布局，构建[目标格局或体系]，引导[资源或要素]向[重点方向]集聚，推动[发展方式]转型，提升[整体效能指标]。

四、提升[支撑领域]保障能力。完善[基础设施或公共服务体系]，补齐[薄弱环节]短板，统筹[要素配置]，增强[抵御风险或服务保障]能力，促进[区域或群体]协调发展。

五、维护规划严肃性。《[规划／方案简称]》一经批准，必须严格执行，未经法定程序不得修改；确需调整的，应按原报批程序报批。要建立[监测评估或考核机制]，强化[监督检查]，对违反规划的行为依法依规追究责任。

六、抓好组织实施。你单位要加强组织领导，健全[工作协调或责任落实机制]，将《[规划／方案简称]》主要目标和任务分解落实到[责任主体]，纳入[考核或评估体系]；[归口审查部委]及有关方面要按职责分工加强指导和监督，确保各项任务落到实处。实施中的重大事项，要及时向我单位报告。

[批复单位]
[日期]

（此件公开发布）
```

## 常见误写
- 误写：长篇核准批复每条都重写下级请示中的背景论证，篇幅冗长却不见结论。→ 修正：表态前置，第一条即给“原则同意”，其后各条只写本机关的处理意见和硬约束，不复述来文背景。
- 误写：各分条主题交叉重叠、详略失衡，读不出维度。→ 修正：按工作维度平行分条（如底线→格局→保障→严肃性→实施），一条一维度，标题化呈现。
- 误写：长批复机械套用“特此批复。”收尾。→ 修正：含执行要求的核准类批复末条写实施保障后直接落款，公开发布的可注“（此件公开发布）”。
