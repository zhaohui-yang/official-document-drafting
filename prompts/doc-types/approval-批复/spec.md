# 批复规范

## 起草要点

- 必给：所批复请示的标题与发文字号、明确表态（同意 / 原则同意 / 不同意＋理由）、对请示各事项的逐项处理意见。
- 主送＝原请示机关（唯一）。
- 有请示才批复；无请示不主动批复。

## 撰写思路

- 起笔：引述来文，「你省《……的请示》（×政〔20××〕×号）收悉。现批复如下」。简短型也可省「现批复如下」直接接「同意……」。
- 两种体例（真实样例并存）：①**简短型**——一事一批，百字内，一句表态加一句落实分工（如「同意……。具体工作由你×商有关部门组织实施」），直接落款；②**长结构型**——核准规划／方案／标准等，可达数千字，按工作维度平行分条（如：安全底线→发展格局→优化布局→维护规划严肃性→实施保障），末条落实责任分工。
- 标题：常把表态词写进标题，如「关于同意……的批复」「关于《……》的批复」，读题即知结论。
- 主送：原则上是原请示机关（唯一）；核准类批复主送可含「请示机关＋归口审查部委」两行（如「××省人民政府、自然资源部」），均与本请示直接相关，不是泛主送序列。
- 谋篇：**表态前置**——首句／第一条即给同意／原则同意／不同意；长批复随后按维度平行分条，对来文事项逐项回应；有请示才批复，一请示一批复。
- 语域（下行）：明确、果断，态度置于首句，不含糊；核准类含量化指标的，硬约束写实（如耕地保有量、生态红线、开发边界不得突破）。
- 结尾：纯短答复用 `特此批复。` 或 `此复。`；含执行要求时用 `请遵照执行。`；真实国务院批复**常不写"特此批复"**，末条／末句后直接落款，公开发布的可注「（此件公开发布）」。
- 批复 vs 复函（易混）：批复是**下行**，答复下级机关请示，标题用「……的批复」，结论刚性；复函是**平行**，答复不相隶属机关来函／商洽，标题用「……的复函」，语气协商。
- 误区：答非所问或超范围答复；漏引来文标题与发文字号；无请示而主动批复；把请示与复函错当批复处理。

## 写作规则

- 适用场景：答复下级机关请示事项。
- 结构重点：对来文的简要回顾、批复结论、执行要求、落款。
- 要素分层：`必备` 为主送单位、来文依据、批复意见、落款；`常见` 为执行要求；`条件项` 为来文文号或时间、批复依据、执行时限、报备或反馈要求、附件。
- 写作提醒：必须直接回应原请示事项，结论不可含糊。
- 分段职责：`来文依据` 只写收到什么请示、围绕什么事项请示；`批复意见` 必须正面作出同意、不同意、原则同意或需调整完善的结论；`执行要求` 写如何落实、何时报送、还需补哪些程序，不能把批复结论藏在执行要求里。
- 常见起句：部委和省级样例中的批复，首段常用“你单位《关于……的请示》（文号）收悉。现批复如下：”或相近句式，先交代来文依据，再直接进入批复意见。
- 对应关系：批复通常实行“一请示一批复”；如原请示包含多个具体事项，批复意见应逐项对应作出明确答复，不笼统写“原则同意”后不交代边界。
- 事实要求：不得编造未提供或未核实的事实、数据、时间、地点、机构名称、人员身份、文件号和政策依据；信息不足时标注“待核实”或保留占位符。
- 常用结尾：特此批复。

## 版式要求

- 基线要求：遵循共享总规则中的“版式与导出”。
- 标题通常用 2 号小标宋体居中排布，宜写明被批复事项。
- 如设置主送单位，放在标题下空一行顶格书写；正文首段常直接写来文依据和“现批复如下”。
- 正文用 3 号仿宋体，首行缩进 2 字符；层级标题按黑体、楷体、仿宋加粗的常规层次处理。
- 批复意见宜按条列出，执行要求另起段或另设条目，不要把批复结论埋在长段中。
- 批复正文宜短、直、硬，不重写下级请示中的长篇背景；不同意、暂不批准或要求补充完善的，应把否定性结论和后续补正要求写清。
- 落款中的发文单位和日期置于文末右侧，正式批复仍应套用本单位发文模板复核。

## 模板

```markdown
# 批复模板

## 标题

关于[请示事项名称]的批复

## 来文依据

[写明收到的请示标题、文号和来文时间。]

## 批复意见

[明确同意、不同意、原则同意或需调整完善的具体意见。]

## 执行要求

[写明后续执行要求、报备要求或注意事项。]

此复。

## 落款

[批复单位]  
[日期]
```
