# 通告示例

## 适用任务
- 用户说：请起草一份关于“我的刀盾”素材使用规范的通告。

## 推荐题名
- 关于规范使用“我的刀盾”传播素材的通告

## 范文
```markdown
# 关于规范使用“我的刀盾”传播素材的通告

为规范“我的刀盾”传播素材的使用，维护内容导向和合法权益，根据《中华人民共和国著作权法》等法律法规和[主管部门]有关规定，现就有关事项通告如下。

一、适用范围

本通告适用于[适用区域/对象]在[施行时段]内使用“我的刀盾”入库传播素材的各类行为，包括复制、传播、改编、商业性使用等。

二、应当遵守的事项

使用入库素材应在标注的可用范围内进行，注明素材来源，不得擅自篡改素材内容、歪曲原意；不得用于违反法律法规和公序良俗的用途；涉及商业性使用的，应事先取得[发布单位]书面同意。

三、禁止的行为

禁止超范围使用、转授权使用未经许可的素材；禁止侵犯他人著作权、肖像权等合法权益；禁止借素材使用从事虚假宣传或牟取不正当利益。

四、执行要求

违反本通告的，由[执法/主管单位]依照《中华人民共和国著作权法》等有关规定予以处理；构成违法的，依法追究相应责任。使用中的具体问题，可向下列联系人咨询。

特此通告。本通告自[施行日期]起施行。

## 落款

[发文单位]
[日期]

## 附注

（联系人：[联系人] 联系电话：[固定电话]，[手机号]）
```

## 常见误写
- 误写：通告只写“请大家自觉规范使用素材”，不写法律依据、适用区域和起止时间。→ 修正：通告应写明“根据《××法》……”的依据，并把适用范围、起止时间、禁止行为和罚则分条写清。
- 误写：把面向公众、带强制约束的须遵守事项写成公告。→ 修正：在一定范围内公布须遵守、周知的事项用通告；向国内外宣布重要或法定事项才用公告，二者不可颠倒。
- 误写：通告写成松散的倡议书，通篇“倡导”“鼓励”，没有“不得”“禁止”“依法处理”等刚性表述。→ 修正：通告语气刚性，应当遵守和禁止的行为要表述明确，并写清违反后的处理依据。
