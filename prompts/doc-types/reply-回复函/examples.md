# 回复函示例

## 适用任务
- 用户说：请就对方来函咨询“我的刀盾”传播素材共享事宜，起草一份回复函。

## 推荐题名
- 关于“我的刀盾”传播素材共享事宜的复函

## 范文
```markdown
# 关于“我的刀盾”传播素材共享事宜的复函

## 主送单位

[来函单位]：

贵单位《关于商请共享“我的刀盾”传播素材的函》（[来文字号]）收悉。经研究，现函复如下：

一、关于素材共享事宜。我单位原则同意向贵单位共享“我的刀盾”相关传播素材，支持双方在宣传工作中加强协作、资源互通。具体共享范围以双方商定的素材清单为准，涉及版权或使用限制的素材，按原始权属约定执行。

二、关于使用要求。共享素材仅限用于贵单位“我的刀盾”相关宣传工作，使用时应注明来源，不得擅自转授第三方、用于商业用途或改变内容导向。如需二次编辑或对外发布，请事先与我单位沟通确认。

三、关于对接安排。建议双方各确定一名联络人，就素材清单确认、文件交付和后续使用对接进行衔接。我单位将于[时限]前将首批素材清单及电子文件移交贵单位，并配合做好使用过程中的协调服务。

特此函复。

## 落款

[发文单位]
[日期]

## 附注

（联系人：[联系人] 联系电话：[固定电话]，[手机号]）
```

## 常见误写
- 误写：开头直接写“现就素材共享事宜回复你们”，不引来文标题和发文字号。→ 修正：起笔先引来文，“贵单位《……》（[来文字号]）收悉。经研究，现函复如下：”。
- 误写：来函问了共享范围、使用要求、对接方式三件事，复函只用一段笼统答“同意配合”。→ 修正：逐项对应答复，做到有问必答、对应清楚。
- 误写：对平行单位用“批复”“请遵照执行”等下行口吻，或写成新的请示。→ 修正：身份平等，称“贵单位”，给出可执行结论，以“特此函复。”收束。
