# 公报示例

## 适用任务
- 用户说：请根据会议和公开信息整理一份“我的刀盾”相关工作情况公报。

## 推荐题名
- “我的刀盾”传播素材整理工作推进会公报

## 范文
```markdown
# “我的刀盾”传播素材整理工作推进会公报
（[会议时间] [会议地点]）

“我的刀盾”传播素材整理工作推进会于[会议时间]在[会议地点]举行。[出席主体]出席会议。会议听取了“我的刀盾”传播素材整理工作进展情况的报告，审议并原则通过了[文件名称]。

一、会议概况

会议在[主持主体]主持下召开。[出席范围]出席会议，[列席范围]列席会议。会议总结了前一阶段素材摸排、归集和入库工作，研究部署了下一步重点任务。

二、主要内容

全会认为，开展“我的刀盾”传播素材整理工作，是盘活用好传播资源、提升内容供给质量和传播效能的基础性、长期性工作，前一阶段各单位扎实推进，累计归集各类素材[数量]件，建立素材台账[数量]份，工作取得阶段性成效。

全会强调，要坚持质量优先、应收尽收、安全合规，把好政治关、内容关、版权关，做到底数清、分类明、可调用、可复用，切实把素材资源转化为传播优势。

全会决定，下一阶段以补齐短板、规范管理、强化复用为重点，于[时间节点]前完成台账完善和重点素材标注，建立长效管理机制。会议要求各单位主要负责同志切实负起领导责任，确保各项任务落到实处。

## 三、后续安排

会议有关精神和审议通过的[文件名称]，将按程序印发执行。
```

## 常见误写
- 误写：把公报写成内部通报或简报，按“背景、问题、措施”铺陈过程性细节，使用口语化表达。→ 修正：公报面向社会公开、强调权威结果，会议公报应交代会议名称、时间地点、出席情况，以“全会认为／强调／决定”领起要点。
- 误写：给会议公报加“各有关单位：”等主送单位，并以“特此公报。”收尾。→ 修正：公报通常不设主送单位，可以结果性、说明性或号召性表述自然收束，不机械套用固定套话。
- 误写：统计公报把初步数当最终数，或列数据时不标注统计口径和时点。→ 修正：分领域列数据时标明口径与时点，初步数、最终数、待核实数据如实标注，不编造、不混用。
