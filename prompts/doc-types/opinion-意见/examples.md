# 意见示例

## 适用任务
- 用户说：请就规范“我的刀盾”传播素材使用提出若干工作意见。

## 推荐题名
- 关于规范“我的刀盾”传播素材使用的意见

## 范文
```markdown
# 关于规范“我的刀盾”传播素材使用的意见

　　为进一步规范“我的刀盾”传播素材使用，提升传播工作质量和水平，根据[依据文件或政策名称]，结合[发文单位]工作实际，现就规范“我的刀盾”传播素材使用提出如下意见。

## 一、总体要求

　　（一）指导思想。坚持以[指导思想表述]为指引，紧紧围绕[工作大局表述]，把规范传播素材使用作为提升传播工作整体效能的重要抓手，统筹谋划、系统推进，努力构建管理规范、运行高效、保障有力的传播素材使用工作格局。

　　（二）基本原则。坚持正确导向，确保素材使用始终服从服务于工作大局；坚持统一管理，确保素材来源清晰、审核严格、使用有序；坚持权责一致，确保各环节责任明确、可追溯、可问责；坚持务实管用，确保各项制度安排立足实际、便于操作、行之有效。

　　（三）工作目标。到[时间节点]，传播素材分类管理机制基本建立，素材审核覆盖率达到[X]%，规范使用率达到[X]%；到[时间节点]，形成来源可溯、审核严密、使用规范、监督有力的长效机制，传播素材使用整体水平显著提升。

## 二、主要任务

　　（一）建立素材分类管理制度。由[牵头单位]牵头，按照素材类型、使用范围和敏感程度，建立分级分类清单，明确各类素材的使用条件和审批权限，实现素材来源可查、使用可控。

　　（二）健全素材审核把关机制。各使用单位对外使用传播素材，须按规定履行审核程序，未经审核的素材一律不得对外发布；对涉及重要事项的素材，应当逐级报审，确保导向正确、表述准确。

　　（三）规范素材使用流程。明确素材调用、加工、发布、归档各环节操作规范，建立使用台账，做到全过程留痕、可追溯，坚决杜绝擅自使用、违规使用。

## 三、保障措施

　　（一）加强组织领导。各单位要把规范传播素材使用摆上重要议事日程，主要负责同志亲自抓，明确分管负责同志和具体承办机构，确保各项任务落到实处。

　　（二）强化监督检查。由[责任单位]牵头建立常态化检查通报机制，定期开展专项检查，对违规使用素材的及时纠正、严肃处理。

　　（三）做好条件保障。各单位要在人员、经费、技术等方面给予必要支持，为规范素材使用提供有力保障。

## 四、组织实施

　　各单位要结合实际制定具体落实办法，明确责任分工和时间节点，于[时间]前将贯彻落实情况报[牵头单位]。[牵头单位]要加强统筹协调和跟踪督办，及时研究解决工作中的重要问题，确保各项措施落地见效。

　　以上意见如无不妥，请批转执行。

## 落款

[发文单位]
[日期]
```

## 常见误写
- 不要把意见写成具体通知事项清单：意见重原则和办法，不是一次性事务布置。
  - 误写：“一、[X]月[X]日报送材料；二、[X]月[X]日召开会议；三、[X]月[X]日前完成报送。”
  - 修正：“（一）建立素材分类管理制度……（二）健全素材审核把关机制……”，按“是什么—怎么办—谁来办”组织。
- 不要在上行报批的意见中误用请示语气。
  - 误写：“当否，请批示。”“妥否，请指示。”
  - 修正：上行报批用“以上意见如无不妥，请批转执行。”；下行部署用“请结合实际认真贯彻执行。”
- 不要缺少原则性导向和措施对应关系，沦为空泛表态。
  - 误写：“要高度重视，狠抓落实，确保取得实效。”（无具体安排）
  - 修正：基本原则写成排比导向句，工作目标带时间节点与量化指标，每项任务对应明确责任主体。
