# 情况专报示例

## 适用任务
- 用户说：请围绕“我的刀盾”传播走势，整理一份给领导看的情况专报。

## 推荐题名
- 关于“我的刀盾”传播情况的专报

## 范文

```markdown
　　　　　关于“我的刀盾”传播情况的专报

　　（信息截止[X月X日X时]　来源：[X个]平台监测及[来源范围]）

　　报送：[报送对象]

　　近日，“我的刀盾”相关内容在网络平台集中扩散、热度持续攀升。经梳理，本轮传播以情绪驱动为主、事实增量有限，目前总体可控，但已出现向重点群体外溢的苗头，需提前研判、稳妥应对。现将有关情况报告如下。

　　一、基本情况

　　[X月X日]以来，“我的刀盾”相关话题先后在[平台一]、[平台二]集中出现。截至[X月X日X时]，相关信息累计[X]条、互动量约[X]万次，其中[X月X日]单日新增[X]条，为本轮峰值。从传播结构看，[X]个账号贡献了约[X]%的转发量，呈现“少数账号引流、多数用户跟转”的特征。从内容看，事实陈述类约占[X]%，观点评论类约占[X]%，情绪宣泄类约占[X]%。需要说明的是，部分高热信息尚未经权威渠道核实，本专报已将其单列为“待核实”，未与已核实事实混计。

　　二、原因分析

　　本轮传播热度上升，主要源于三方面因素叠加。一是话题本身具有较强情绪共鸣点，容易在特定群体中引发代入和转发。二是[X]个高活跃账号在短时间内集中发声，形成了引流效应，放大了传播声量。三是初期权威信息供给不足，给猜测性、情绪化内容留下了发酵空间。综合判断，当前热度更多由情绪和传播机制驱动，而非新增实质性事实，这一判断为后续处置提供了基本依据。

　　三、风险研判

　　从趋势外推看，预计未来[X]天话题热度仍将高位运行，存在再现单日峰值的可能；若无新的刺激性信息，热度有望在[X]天后逐步回落。按风险分级，目前总体列为[中等／需关注]等级：核心风险点在于情绪叠加可能引发非理性跟风，次生风险在于个别不实信息被反复转引、固化为“既定印象”。从关联影响看，话题已出现向[关联领域／重点群体]外溢的苗头，若处置不及时，可能波及[关联事项]，需重点防范。以上均为研判，与前述已核实事实分列，供领导参考。

　　四、工作建议

　　针对上述情况，建议从四个方面着手应对。一是加强监测预警。建议依托[X个]平台开展[全天候／每日X次]监测，紧盯[X]个引流账号和[X]个高活跃社群，对苗头性、倾向性信息做到早发现、早报告，每日形成简要动态报送领导。二是及时释放权威信息。建议由[责任单位]牵头，针对已核实的关键事实，通过[官方渠道]稳妥发声、回应关切，压缩猜测性内容的发酵空间，避免“信息真空”被情绪填补。三是分级稳妥处置。对明显违法违规、恶意造谣的内容，建议依规依法处置；对一般性情绪表达，以引导疏导为主，不简单“一删了之”，防止激化矛盾、引发二次传播。四是健全协同机制。建议建立[牵头单位]统筹、[相关单位]参与的会商机制，明确信息核实、对外发声、应急处置的责任分工和时限要求，确保一旦热度异常升级能够快速联动、形成合力。

　　特此报告。

　　[报送单位]
　　[X年X月X日]
```

## 常见误写
- 有情况无建议（最典型）：通篇罗列现象、数据和走势，却没有对策建议 → 对策建议应是重点、约占全文三分之一，分点写清谁来干、干什么、什么时限。
- 事实与研判混写：把“预计”“可能”“倾向于”等判断和已核实事实混在一段 → 研判段单独成段、明确标注为判断，未核实信息一律列为“待核实”“网传情况”。
- 面面俱到不聚焦：背景、过程、各方反应平均用力，淹没主要矛盾 → 聚焦核心风险点和关键时间节点，背景从简，把笔墨留给研判和建议。
