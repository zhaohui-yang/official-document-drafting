# 议案示例

## 适用任务
- 用户说：请就［事项名称］向同级人大及其常委会提请审议，拟制一份议案。

## 推荐题名
- ［××政府］关于提请审议［事项名称］的议案

## 范文
```markdown
# ［××政府］关于提请审议［事项名称］的议案

［××人民代表大会第［届次］次会议主席团／××人民代表大会常务委员会］：

　　根据《［法律或组织法名称］》第［条款］的规定，现将《［议案所附草案／方案名称］》提请［会议届次］审议。

　　近年来，随着［领域或背景情况概述］的不断发展，原有［制度或安排］已难以适应［现实需要］。为［立法或决策目的］，依法推进［工作事项］，经［研究或论证程序］，形成本议案。提请审议事项的必要性、可行性及主要考虑，已在所附《关于〈［草案名称］〉的说明》中作了具体阐述。

　　议案的主要内容为：一是［主要内容第一项］；二是［主要内容第二项］；三是［主要内容第三项］。有关具体条款及技术性安排，详见所附《［草案名称］》。

　　以上议案及所附草案、说明，特提请审议。

　　附件：1.《［草案名称］》
　　　　　2.《关于〈［草案名称］〉的说明》

　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　［提请单位］

　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　［日期］
```

## 常见误写
- 误写：把议案写成「请示」，结尾用「妥否，请批示」。
  → 修正：议案是法定提案主体向同级人大或常委会在法定审议程序中行文，结尾须落到「特提请审议」，不用请示的请批语。
- 误写：提案主体或受文对象错位，如以部门名义、向上级机关「提请审议」。
  → 修正：议案只能由政府等法定提案主体向同级人大及其常委会行文，主送唯一、不可多头；主体或程序不符时应改用其他文种。
- 误写：正文把法律草案全文、预算明细等技术性条款硬塞进去。
  → 修正：正文重在提请与说明，按案据—方案—结语三段展开；草案正文、决算或预算调整等技术材料宜由附件承载。
