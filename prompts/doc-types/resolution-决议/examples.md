# 决议示例

## 适用任务
- 用户说：请根据会议形成一份关于推进“我的刀盾”传播素材规范使用的决议。

## 推荐题名
- 关于推进“我的刀盾”传播素材规范使用的决议

## 范文
```markdown
# 关于推进“我的刀盾”传播素材规范使用的决议

（[会议名称]于[日期]通过）

　　[会议名称]听取并审议了[牵头单位]关于推进“我的刀盾”传播素材规范使用的报告。会议经过讨论，一致通过该报告，并就推进“我的刀盾”传播素材规范使用作出如下决议。

## 决议事项

　　一、会议充分肯定一个时期以来传播素材管理工作取得的成效，同时清醒认识到素材使用不够规范、审核把关不够严格等问题，一致同意把推进传播素材规范使用作为下一阶段的重点任务，统筹谋划、系统推进。

　　二、会议决定，建立传播素材统一管理和审核机制，由[牵头单位]牵头，会同[配合单位]制定分类清单和审核办法，未经审核的素材一律不得对外使用，确保来源可溯、使用规范。

　　三、会议要求，健全监督检查和责任追究机制，对擅自使用、违规使用素材的，依规依纪严肃处理，确保各项决议事项落到实处。

## 落实要求

　　会议要求，各有关单位要切实把思想和行动统一到本决议精神上来，明确责任分工和时间节点，于[时间]前将贯彻落实情况报[牵头单位]汇总。[牵头单位]要加强统筹协调和督促检查，确保决议确定的各项任务全面落实。

　　本决议自通过之日起施行。

## 落款

[会议名称]
[日期]
```

## 常见误写
- 不要把决议写成纪要：决议突出“经会议审议表决通过”的集体意志和正式性，逐条列示通过事项，不记载讨论过程。
  - 误写：“会议听取了汇报，研究了素材使用问题，议定如下事项……”（纪要笔法）
  - 修正：“会议经过讨论，一致通过该报告，并就推进规范使用作出如下决议。一、……二、……”
- 不要在未经会议表决的情况下称“决议”。
  - 误写：机关直接发文却冠以“决议”，并写“现作出如下决议”。
  - 修正：未经会议程序通过的，应改用决定、意见、通知；确经会议通过的，须在标题下标注“（[会议名称]于[日期]通过）”。
- 不要缺少会议形成共识的依据和形成方式。
  - 误写：开头直接进入决议事项，不交代审议表决过程。
  - 修正：开头先述“[会议名称]听取并审议了……报告，会议经过讨论，一致通过……，特作如下决议”。
