## 撰写思路总纲

结构是骨架，思路是灵魂。先想清楚再落笔，顺序是：**定文种与方向 → 定语域档位 → 谋篇布局 → 起笔 → 自检**。结构可按事项调整，但每一步的取舍都要有理由，不为形式完整而堆砌板块。

本项目默认语域基准对标**中央和国家部委**的高规格行文；省级机关行文在此基础上酌情下调正式度。无论档位高低，都不得为追求「文气」而编造事实、数据或依据。

## 起笔四式与选择逻辑

公文开头第一段的写法，决定全文基调。四种起笔范式按事项性质选择：

- **缘由式（因事而发）**：直接交代触发事项。适合通报、报告、情况专报、简报——"近期，……"。
- **依据式（奉命而行）**：先引上位依据再展开。适合转发/印发型通知、批复、贯彻落实类意见——"根据《……》和……会议精神，……"。
- **目的式（为标而立）**：以"为了……"统领，点明目标再部署。适合部署型通知、工作方案、实施意见——"为深入贯彻……，扎实推进……，现就……"。
- **导语式（先概后详）**：用一句高度概括的导语领起，再分述。适合公报、统计公报、综合性汇报材料、纪要。

选择判据：上位依据明确且需贯彻的，用依据式；自主部署且有清晰目标的，用目的式；客观陈述既成事实的，用缘由式或导语式。一篇之内可叠用（先依据后目的），但开头不超过三句即应转入主体。

## 谋篇布局与行文方向的对应

主体怎么排，由行文方向和文种性质决定，不套用同一种展开法：

- **下行部署文（通知、意见、决定、工作方案）**：用**总分式/并列式**。规范性文体固定骨架为"**总体要求（指导思想＋基本原则＋工作目标）→ 主要任务 → 保障措施 →（组织实施）**"。目标须带时间节点与量化指标，任务用"动词＋名词"的并列条目，保障从组织、机制、资金、督查维度落地。
- **上行情况文（报告、情况专报、汇报材料）**：用**递进式**——"情况 → 分析 → 建议"。专报尤其要把对策建议写足，约占全文三分之一；研判段要写出趋势、风险分级与关联影响，不与事实罗列混为一谈。
- **请求/答复文（请示、批复、函）**：用**单线直叙**，一文一事。请示按"缘由 → 单一事项 → 请批语"；批复、复函先引来文标题与发文字号，再开门见山表态。
- **公布告知文（公告、通告、命令）**：用**条款式**，事项分条、刚性表述（"禁止""不得""自……起施行"）。
- **会议文（纪要、决议）**：以"会议"为主语统领，提炼议定事项，不作流水记录。

判断锚点：综合性材料（报告、纪要、总结、专报、汇报）的二级标题下，通常先用 3 至 5 句话概述本节，再用"一是、二是、三是"段内分点展开，每点 5 至 7 句；执行性内容（责任分工、时限、单条结论）可从简。

## 省部级以上语域

中央、国家部委行文的语言质感，集中体现在四处：

- **政论语言与整散结合**：定调段、总体要求段适度使用对偶、排比、整句，增强庄重感与气势；但只在统领性段落用，具体部署段仍以平实可执行的散句为主，不通篇排比。范例语感：「准确把握……的目标定位，统筹推进……的重点任务，切实增强……的系统性、整体性、协同性。」
- **政治站位段**：高规格部署文常在开篇设一段政治定调（讲意义、讲要求、提高站位），再转入具体任务。无明确精神可引时，宁可不写，也不编造定调话语。
- **引据精确**：引用文件先写标题、再写发文字号；引用会议先写完整会议名称与届次；引用上级精神用"根据……精神"。届次、文号、日期一律写全，不用"上级有关文件""某次会议"之类含混表述。文号格式为"机关代字〔年份〕顺序号"，六角括号、不加"第"、不补零（如〔2026〕5号）。
- **数据用法**：去口语化，结论先行、数据支撑——"结论句＋硬数据＋必要案例"。不会写的范围用规范化表述（"x万元以上""同比增长x个百分点"），不臆造精确数字；引用统计数据应交代口径与时点。

**正式度三档（默认取最高档）**：①事务级（内部简报、汇报便条，可适度务实灵活）；②单位正式级（一般机关公文）；③省部级政论级（中央、部委高规格文，政论笔法＋精确引据＋严整结构）。除非用户指明面向基层或内部，默认按③起草。

## 易混文种辨析

按"**行文方向 ＋ 目的 ＋ 是否需对方回应**"三维快速判别，避免文种误用：

- **报告 vs 请示**：都上行；报告汇报情况、不要求回复、可一文数事；请示请求批准、必须等批复、一文一事。**报告里绝不夹带请批事项**。
- **通知 vs 意见 vs 决定**：通知重部署执行；意见重原则与办法；决定重重大决断、奖惩与调整。
- **决定 vs 决议**：决定可由机关直接作出；决议必经会议讨论表决、以会议名义发布。
- **通报 vs 通告**：通报对内，表彰/批评/告知情况；通告对外，公布应共同遵守的事项，带强制语气与法律依据。
- **公告 vs 通告**：公告向国内外宣布重要或法定事项，发文机关层级较高；通告面向一定范围公布须遵守事项。
- **函 vs 通知/请示**：不相隶属或平行机关之间商洽、询问、答复、请求批准，一律用函，不因事项重要就升格为请示或通知。
- **纪要 vs 记录**：纪要提炼议定事项、需审定印发；记录是原始逐字存档。未达成一致的不写入议定事项。

辨不准时，回到三维：先定方向（上/下/平/公开），再定目的（请求/汇报/部署/告知/商洽/记载），即可收敛到正确文种。

## 行文规则硬约束（《党政机关公文处理工作条例》）

- **确有必要**：行文须确有必要、讲求实效，可发可不发的不发。
- **上行只主送一个上级**：请示、报告原则上只主送一个上级机关，可抄送相关上级和同级，**不抄送下级**。
- **一文一事**：请示一文一事；**不得在报告等非请示性公文中夹带请示事项**。
- **不越级**：一般不越级行文；确需越级的，须同时抄送被越过的机关。
- **不径送领导个人**：除领导直接交办外，不得以本机关名义向上级机关负责人报送公文。
- **不原文转报**：转报下级请示须提出倾向性意见，不原文照转。
- **联合行文有限**：党委、政府各自职权范围内的工作不联合行文；部门内设机构除办公厅（室）外不对外正式行文。

## 格式硬规范（GB/T 9704-2012、GB/T 15834/15835）

- **发文字号**：机关代字＋〔年份〕＋顺序号＋"号"；年份用六角括号〔〕（不用 [] 或【】），**不加"第"字、不补零**（写 `〔2026〕5号`，不写 `〔2026〕第05号`）。
- **成文日期**：用阿拉伯数字，年份写全称，**月、日不补前导零**（写 `2026年6月1日`，不写 `2026年06月01日`）。
- **标题标点**：标题一般不用标点；仅法规、规章、文件、方案等需保留全称时用书名号《》，机构名、活动名不用书名号。
- **正文层级序号**：`一、`（顿号）→ `（一）`（无标点）→ `1.`（实心圆点）→ `（1）`（无标点），逐级不跳、不混用；一级黑体、二级楷体、三/四级仿宋。
- **数字**：年份、统计、计量、编号用阿拉伯数字（年份写全、不简写两位）；概数、定型词用汉字。
- **取消主题词**：2012 版已取消"主题词"，不再编排。

## 常用开头语（精确到字）

- 印发/转发通知 → `《……》已经〔国务院/党中央〕同意，现印发给你们，请认真贯彻执行。`／`现转发给你们，请认真贯彻执行。`
- 部署通知 → `为〔目的〕，现就……有关事项通知如下。`／`经〔机关〕批准，现将……通知如下。`
- 意见/方案 → `为……，现提出如下意见。`／`为……，根据……，结合……实际，制定本方案。`；总体要求段领起 `坚持以习近平新时代中国特色社会主义思想为指导，……`
- 请示 → `因……，现将有关事项请示如下。`（缘由从简、一文一事）
- 报告 → `现将……报告如下。`
- 批复/复函 → `你省《关于……的请示》（×〔20××〕×号）收悉。现批复如下：`（复函作 `……收悉。经研究，现函复如下：`）
- 通报 → 表彰 `经〔机关〕同意，现将……通报如下。`；情况/批评 `近期，……`
- 公告/通告 → `根据《……》，现将有关事项公告/通告如下。`
- 决议 → 标题正下方括注 `（〔年月日〕〔会议全称〕通过）`，开头 `会议听取和审议了……`
- 命令（令）→ `《……》已经……通过，现予公布，自……起施行。`

## 结尾用语与文种强绑定

结尾套语须与文种一一对应，不张冠李戴，也不与开头"现将……如下"重复造成冗赘：

- 通知 → `特此通知。`
- 通报 → `现提出以下工作要求……` / `希望各地区各部门引以为戒。`
- 报告 → `特此报告。`
- 请示 → `妥否，请批示。` / `当否，请批复。`
- 批复 → `特此批复。` / `此复。`（含执行要求时 `请遵照执行。`）
- 函 → 去函 `特此函达。` / `特此函商。`；复函 `特此函复。`；通用 `请予支持为盼。`
- 意见（上行报批）→ `以上意见如无不妥，请批转执行。`
- 决定 → `特此决定。`
- 决议 → `特作如下决议。`
- 公告 → `特此公告。`
- 通告 → `特此通告。` / `本通告自……起施行。`
- 命令（令）→ `现予公布，自……起施行。`
- 议案 → `特提请审议。`

## 落笔后自检

起草完成后，除核对各板块分工（背景段答"为什么写"、进展段答"做到哪里"、问题段答"卡在哪里"、要求段答"下一步怎么做、由谁做、何时做"）外，再加三问：

1. **语域是否匹配**：语气、正式度、引据方式是否符合该文种和行文方向？上行不卑、下行不傲、平行不命令。
2. **文种是否用对**：用三维辨析复核一遍，尤其报告/请示、函/通知、决定/决议是否错配。
3. **真实性是否兜底**：政论定调、数据、文号、届次是否都有材料支撑？凡无依据，一律改为占位符或留待核实，绝不编造。
4. **格式红线是否踩**：文号是否〔〕且不加"第"不补零、成文日期月日是否未补零、标题是否未误加句号、层级序号标点是否正确、是否残留"主题词"；上行是否多头主送、报告是否夹带请示。
