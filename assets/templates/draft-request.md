# 起草请求模板

这是一份**统一的填空式起草请求**，管全部文种。用法：复制一份 → 按需改「配置项」（已是默认值）
→ 照「本文种起草要点」填「需你提供」→ 整份交给公文写作 skill，或粘到离线/网页版 prompt
的 `# User Prompt` 处生成对应公文。只改你想改的字段，其余保持默认即可。

## 配置项（已是默认值，想改哪项就改哪项，其余保持默认）

- 目标文种：报告
  （清单：通知 报告 请示 批复 函 回复函 纪要 意见 决定 决议 公告 通告 命令（令） 议案 公报 通报 简报 情况专报 汇报材料 工作总结 工作方案 讲话稿）
- 任务类型：起草成稿（可改：提纲 / 改写 / 摘要 / 规范化整理）
- 语域：中央·国家部委正式行文（可改：省级机关 / 一般单位）
- 篇幅：完整结构（可改：只要提纲 / 精简）
- 导出 Word：否（可改：是，则成稿后再用 generate_docx.py 导出）

## 本文种起草要点

「这个文种该提供什么」见对应文种规则的 `## 起草要点` 段——也已内联在该文种的离线/网页版 prompt 里。
照那份清单准备下面的「需你提供」，缺哪项补哪项。

## 需你提供

- 主送对象：[填写收文机关；公布性文种（公告/通告/公报）可留空，未定写 [主送单位]]
- 任务说明：[填写要写什么、主题与目的、时间要求]
- 原始材料：[逐条粘贴已确认的事实，带来源/日期；较长先压成要点；未确认的留占位、标待核实]

## 输出要求

- 默认直接输出最终 Markdown 成稿，不输出分析过程或思维链。
- 信息不足时保留占位符或标注待核实，不编造事实、数据、文号、日期。
